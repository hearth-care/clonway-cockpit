# Example shared handbook

These files illustrate the shared-company-memory format read by
`clonway_cockpit.shared_memory.SharedMemory` — one markdown fact per file, with
`name`/`kind`/`summary`/`source`/`as_of` frontmatter. See `docs/shared-memory.md`.

**This is illustrative data only — fictional, not a real handbook.** A real handbook
(residents, families, staff, suppliers) is sensitive: it lives in a configured /
gitignored directory the consumer injects, **never** committed to the framework repo.
This README has no frontmatter, so the reader skips it (it isn't a fact).
